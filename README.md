# Расписание YOGI ROOM

Редактор недельного расписания студий и выгрузка картинки для мессенджеров.

## Где что лежит

- Код: Mac `~/Projects/yr-schedule` = GitHub `olerain/yr-schedule`.
- Документы и выгрузки: Google Drive `AI PROJECTS/G-yr-schedule` (там же `_КОНТЕКСТ`): https://drive.google.com/drive/folders/1oXSm3QrL3pXZ6c73aeJL7EMI9xO_4jkE
- Медиа (Яндекс `disk:/AI PROJECTS/Y-yr-schedule`): пока нет.
- `slides-codex/` — ранняя версия в Google Slides от Codex (15–28.10.2026), только генераторы; PPTX/PDF лежат в G-папке.

## Как устроено

- Сайт: https://olerain.github.io/yr-schedule/ (GitHub Pages, ветка `main`, корень).
- Данные: Supabase, проект `yogi-room-admin-bot`, таблицы `sched_settings`, `sched_dirs`, `sched_classes`, `sched_editors`.
- Студии — строки `sched_settings` (`studio` — ключ, `name` — название в переключателе, `sort` — порядок). Ссылка на конкретную студию: `?studio=optikov`.
- Читать может любой. Менять — только вошедший по ссылке из письма пользователь из `sched_editors`:
  - `studios = null` — админ: все студии и общие направления;
  - `studios = '{moskovsky}'` — только перечисленные студии. Проверку делает база (RLS, функции `sched_can_edit`, `sched_is_admin`).
- Добавить редактора студии: `insert into public.sched_editors (email, studios) values ('name@example.com', '{optikov}');`
- Два вида картинки, переключатель вверху: «Для клиентов» (бирюзовый список по дням, 1080 px) — основной; «Сетка (внутренняя)» — сетка по времени, 1600 px. Выбор запоминается в браузере.
- Ссылка на приложение (`sched_settings.app_url`, сейчас onelink.to) — кнопка «Записаться в приложении» на живой странице. С 07.11 QR в картинках не выводится.
- Ключ в `index.html` — публичный (publishable), секретов в репозитории нет.

## Новое с 06.11.2026

- **Филиалы.** 16 студий сети, ключи и залы Listok — в `sched_settings` (`listok_rooms`). Список офисов и залов проверен по виджету Listok 06.11.
- **Импорт из Listok.** Кнопка «Обновить из Listok» во вкладке «Занятия» (эта или следующая неделя). Данные даёт Edge-функция `sched-listok` (`supabase/functions/sched-listok`), названия приводит к виду постера `listok.js`. Если правило ошиблось, точное соответствие можно добавить в словарь `sched_listok_map` (правит админ). Мастер-классы и открытые уроки из Listok уходят в `sched_events`. Замена недели идёт одной транзакцией: `sched_replace_week`.
- **Форматы.** «Пост» (1080 по ширине), «Сторис 9:16» (1080×1920), «Квадрат» (1080×1080, дни в две колонки). Для сторис и квадрата блок дней сам масштабируется под размер (`--k`).
- **Отметки и преподаватели.** У занятия есть поля «Отметка» (новое, замена, отмена) и «Преподаватель». Имена в картинке включаются галочкой в «Шапка и подвал».
- **Мастер-классы.** Отдельная вкладка. На картинке и живой странице показываются ближайшие 3–4 недели.
- **Живая страница для клиентов:** `live.html?studio=<ключ>`. Работает без входа, под телефон, обновляется сама.
- **Автопостинг в Telegram:** `.github/workflows/autopost.yml`, по понедельникам в 07:17 по Москве. Нужен секрет репозитория `TELEGRAM_BOT_TOKEN`. Бот должен быть админом канала. Канал и галочка задаются в редакторе. Пробный прогон: Actions → «Автопостинг…» → Run workflow → studio + dry_run.
- Параметры ссылки редактора: `?studio=…&mode=list|grid&fmt=post|story|square`.

- **Города (07.11.2026).** Санкт-Петербург, Москва (12 студий), Воронеж (2). У каждого города своя CRM Listok: `sched_settings.listok_crm` = `spb` / `msk` / `vrn`, город — `city`. Функция импорта принимает `?crm=`. Чебоксары на сайте yogiroom.ru пока без адресов.
